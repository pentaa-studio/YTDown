# YTDown
YTDown - Youtube Downloader

Run `` npm install `` to install dependencies before start app

To start app, run `` npm start `` or `` npm server `` to start only server

## Minimal Requeriments
Node v16.14.0

NPM 9.6.5

### Production (Vercel)

YouTube blocks datacenter IPs. If downloads work locally but fail in production, configure a residential proxy: see [docs/PROXY.md](docs/PROXY.md).
